# 康记 · 个人健康记录

一个纯静态的个人健康数据记录小工具，**无需安装任何环境，双击 `index.html` 即可使用**。

## 功能

| 模块 | 说明 |
| --- | --- |
| 📊 仪表盘 | 最新体重 / BMI / 血压 / 心率 / 睡眠 / 步数一目了然，附近 30 天趋势图 |
| 📝 健康记录 | 按天记录体重、血压、心率、睡眠时长、步数与备注，支持编辑和删除 |
| 📈 趋势图表 | 体重、血压（收缩压/舒张压双线）、心率、睡眠、步数五类趋势，可切换近 7 / 30 / 90 天 / 全部，悬停查看明细 |
| 🧮 健康工具 | BMI 计算器（中国成人标准）、基础代谢 BMR/TDEE、每日饮水与理想体重建议、血压分级参考表 |
| ⚙️ 设置与数据 | 个人信息（用于各项计算）、JSON 备份导出/导入、示例数据、清空数据 |

首次使用可点击「✨ 载入示例数据」快速查看效果。

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，零依赖、零构建，可离线使用。
- 图表为手写的轻量 SVG 折线图组件（`js/charts.js`），支持断点、悬停提示、自适应重绘。
- 数据保存在浏览器 `localStorage` 中：
  - **不会上传到任何服务器**，仅保存在当前浏览器；
  - 换浏览器 / 换电脑 / 清理浏览器数据会导致记录丢失，请先用「设置与数据 → 导出备份」保存 JSON 文件；
  - 备份文件可随时通过「导入备份」恢复。
- 按中国成人标准判定 BMI 与血压分级；所有判定仅供参考，不构成医疗建议。
